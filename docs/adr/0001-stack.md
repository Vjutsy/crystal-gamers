# ADR-0001: Технологічний стек

- Статус: прийнято
- Дата: 2026-11-24

## Контекст

Потрібна динамічна 2.5D-гра в браузері з онлайн-кооперативом до 4 гравців. Автор хоче максимально використовувати Node.js/TypeScript і працює в парі з AI.

## Рішення

- **Мова:** TypeScript (strict) усюди.
- **Клієнт:** Babylon.js 9 + Vite. Повноцінний 3D-рушій (анімації, glTF, інспектор), офіційний туторіал разом із Colyseus.
- **Сервер:** Colyseus 0.18 на Node.js — кімнати, матчмейкінг, синхронізація стану схемами, авторитетна модель.
- **Спільний код:** `packages/shared` — симуляція з фіксованим кроком, однакова на клієнті й сервері.
- **Монорепо:** pnpm workspaces. Якість: Biome (lint/format), Vitest, GitHub Actions.
- **Хостинг на старті:** клієнт — GitHub Pages; сервер — безкоштовний тариф (обирається у Фазі 2).

## Альтернативи

- Godot 4 (GDScript) — сильний редактор, але автор обрав стек на JS/TS.
- Three.js — легший, але ігрові системи довелося б збирати самостійно.
- Власний WebSocket-сервер — більше контролю, але Colyseus дає кімнати й синхронізацію готовими.

## Наслідки

- Фізику для симуляції треба запускати і в браузері, і в Node → окремий ADR-0002 (кандидат: Rapier) у Фазі 1.
- Вебзбірка має бути легкою: імпортувати модулі Babylon точково (tree-shaking), а не весь пакет.

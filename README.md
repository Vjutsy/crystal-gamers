# Crystal Gamers

Кооперативний 2.5D-екшен у браузері на 1–4 гравців, натхненний Sonic 3D Blast.
Темне фентезі з коміксним лайн-артом у дусі «тривожної казки», ізометрична камера, четверо героїв зі своєю зброєю та здібністю.

**Стан:** Фаза 1 — відчуття руху (фінальний плейтест). Повний план: [docs/plan.md](docs/plan.md).

## Запуск

Потрібні Node.js 22+ і pnpm (`corepack enable`).

```bash
pnpm install
pnpm dev        # клієнт http://localhost:5173 + сервер ws://localhost:2567
```

Відкрий http://localhost:5173 у кількох вкладках — кожна вкладка стане окремим гравцем у кімнаті.
Без запущеного сервера гра працює в одиночному режимі.

Керування: WASD або стрілки.

## Структура

| Папка             | Що всередині                                 |
| ----------------- | -------------------------------------------- |
| `apps/client`     | Vite + Babylon.js 9: рендер, ввід, інтерфейс |
| `apps/server`     | Colyseus: кімнати, авторитетна симуляція     |
| `packages/shared` | Логіка гри, спільна для клієнта й сервера    |
| `docs/adr`        | Архітектурні рішення                         |
| `docs/specs`      | Специфікації фіч                             |

## Перевірки

```bash
pnpm check      # lint + typecheck + тести
pnpm build      # збірка
```
